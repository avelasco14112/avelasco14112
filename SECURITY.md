# 🔐 Security Policy - Avelasco Gaming

## 📌 Supported Versions

Estas son las versiones del proyecto que reciben actualizaciones de seguridad:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| 0.9.x   | :white_check_mark: |
| < 0.9   | :x:                |

---

## 🚨 Reporting a Vulnerability

Si encuentras un problema de seguridad en la web de Avelasco Gaming, puedes reportarlo de forma privada.

### 📩 Cómo reportarlo:
- Abre un issue privado en GitHub (si está disponible)
- O contacta directamente al creador del proyecto
- No publiques el fallo en público hasta que se haya solucionado

### ⏱️ Respuesta:
- Intentaremos responder en un plazo de **24–72 horas**
- Si el fallo es válido, se corregirá lo antes posible

### ✔️ Si se acepta:
- Se lanzará una actualización corrigiendo el problema
- Se te podrá mencionar como descubridor (si lo deseas)

### ❌ Si se rechaza:
- Se explicará el motivo de forma clara y respetuosa

---

## ⚠️ Reglas importantes

- No realizar pruebas de hacking sin permiso
- No atacar la web ni sus usuarios
- No explotar vulnerabilidades de forma pública

Gracias por ayudar a mejorar la seguridad de Avelasco Gaming 🔐
